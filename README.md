## 📖 Overview

**Analog Clock** is a real-time analog clock built with JavaScript and CSS animations. It displays the current time with hour, minute, and second hands that update every second.

> 🎯 **Purpose:** JavaScript Date API and CSS animation practice

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🕒 **Real-Time** | Updates every second |
| 🕰️ **Analog Display** | Hour, minute, second hands |
| 🎨 **CSS Animations** | Smooth hand movements |
| 📱 **Responsive** | Works on all devices |
| ⚡ **No Dependencies** | Pure HTML/CSS/JS |
